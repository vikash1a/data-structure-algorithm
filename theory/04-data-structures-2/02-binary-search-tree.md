## Binary Search Tree

Properties  
- All left node smaller and right node greater than parent for each n  
- No duplicate nodes allowed  

Basic  
 - Search and Insertion	  
    Brute force  
 - Delete   
    Simple if node has 0 or 1 node  
    If node has 2 node, replace with inorder successor  
 - Advantage of BST over Hash  
         In range queries  

Construction and Conversion  
 - Convert bst from preorder transversal  
    Using stack  
    Using recursion, range - check later
